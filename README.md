# Number Guessing Game

A command-line number guessing game built with Python.

## Features
- Multiple difficulty levels
- Score system
- Input validation
- Smart hints
- Replay functionality

## Difficulty Modes
| Mode | Range | Attempts |
|------|------|------|
| Easy | 1-20 | 7 |
| Medium | 1-50 | 8 |
| Hard | 1-100 | 10 |

## How to Run

```bash
python game.py
